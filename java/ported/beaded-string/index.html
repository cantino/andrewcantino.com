Exploring Waves on a Beaded String

N beads on a stretched string. Watch how high mode numbers alias onto the low fundamental modes.

Mode: 1
Masses: 4

Only N distinct standing-wave patterns can exist on N beads. Asking for a mode number higher than N folds back ("aliases") onto one of those fundamentals — the beads (black dots) trace exactly the same motion even though the continuous blue curve wiggles faster. The small graph plots the dispersion relation ωn ∝ sin(nπ/2(N+1)).
